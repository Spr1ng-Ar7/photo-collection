# 枭潼 · 摄影作品集

> 以光为笔，以影为墨 — 一个带氛围感与创意交互的个人摄影作品展示站。

冷调莫兰迪色系 · 中英双语 · 整屏分页 · 纯静态前端（无构建、无依赖）。

## 🧱 技术栈

- **纯静态**：HTML + CSS + 原生 JavaScript，无构建、无框架、无运行时依赖
- **图片**：Unsplash CDN（`images.unsplash.com`）+ Picsum 固定 ID（`picsum.photos`）
- **字体**：Google Fonts — Cormorant Garamond / Inter / Noto Serif SC / Noto Sans SC / Ma Shan Zheng / Caveat
- **持久化**：`localStorage`（照片编辑、无后端）
- **Canvas**：雾化擦除 + 明信片合成

## 🚀 本地运行

无需安装，任意静态服务器即可：

```bash
# 方式一：Python
python3 -m http.server 8000

# 方式二：Node（需安装）
npx serve .

# 方式三：PHP
php -S localhost:8000
```

然后浏览器打开 `http://localhost:8000/`。

> 不能用 `file://` 直接打开，否则 `localStorage`、字体加载、canvas 跨域等会受限。

## 🖱️ 使用说明

### 导航
- 鼠标滚轮 / 键盘方向键 / PageUp/PageDown 在 5 幕间切换
- 右侧半露轮盘可拖拽旋转，松手吸附到最近场景；点击场景名直达
- 品牌名「枭潼」回开场

### 浏览地区
- 在欧陆 / 国内轮盘上拖动或点击国家名 → 右侧面板显示地区简介
- 点击「进入相册」或高亮项 → 跳转至该地区手记页

### 编辑照片
1. 进入任意地区手记页，点击顶栏「编辑照片」
2. 在弹出面板中：
   - **取消勾选「展示」** → 该照片从网站（头版 / 照片流 / 相册）隐藏
   - **点击「×」** → 删除该照片
   - **填写 URL + 中英文说明** → 新增照片
3. 点击「完成 · 刷新页面」生效
4. 点击「重置该地区为默认」可清除所有编辑

编辑数据存于浏览器 `localStorage`（key: `atlas-photo-overrides-v1`），换浏览器或清除缓存后恢复默认。

### 制作明信片
- 入口：相册内「✉ 明信片」按钮 / 地区页顶栏与底部「明信片」按钮 / 尾声页「做一张明信片」
- 可修改留言、署名、邮戳地，或上传本地图片
- 点击「保存明信片」导出 PNG（受图片 CORS 限制，跨域图可能无法导出，建议上传本地图）

## 🗂️ 数据结构

### 地区数据（`js/data.js`）

```js
{
  id: 'iceland',
  cn: '冰岛', en: 'ICELAND', alias: '冰与火之岛',
  line: '黑沙滩尽头，极光落进海里。',
  notes: [                        // 手记（2 段）
    { h: 'JOURNAL · 手记', p: '…' },
    { h: 'FRAME · 笔记',   p: '…' }
  ],
  photos: [                       // 照片（自动分配稳定 ID）
    { src, cn, en }
  ]
}
```

### PhotoStore（照片编辑层）

编辑不修改原始数据，而是以覆盖层形式存入 `localStorage`：

```
{
  added:   { [regionId]: [ {id, src, cn, en, hidden} ] },
  removed: { [regionId]: [photoId] },
  hidden:  { [regionId]: [photoId] }
}
```

加载时 `PhotoStore.applyAll()` 将「基础 - 删除 + 新增」合并回 `region.photos`，被隐藏的照片带 `hidden:true`；展示层统一用 `ATLAS.display(region)` 过滤。

## 🛠️ 自定义

### 替换品牌名
全站搜索 `枭潼` / `XIAO TONG` 并替换为你的名字（含开场大字、品牌栏、页脚署名、明信片默认落款等）。

### 新增地区
在 `js/data.js` 的 `ATLAS.groups.europe` 或 `china` 数组中追加一个地区对象，填写 `id / cn / en / alias / line / notes / photos` 即可，轮盘与手记页会自动渲染。

### 替换占位图片
将 `photos` 中的 `src` 替换为你的实拍图 URL（建议 1600×1000 以上）。本地图片放入 `images/` 目录后用相对路径引用。

### 缓存刷新
修改 JS 后在 HTML 的 `<script src="…">` 末尾递增版本号（如 `?v=7`）以破除浏览器缓存。

## ⚠️ 注意事项

1. **明信片导出**：Unsplash / Picsum 图片虽带 CORS 头，但部分网络环境下 `canvas.toDataURL` 仍可能因跨域失败；遇到导出问题请改用「上传图片」功能。
2. **localStorage**：照片编辑仅存于当前浏览器，不会同步到其他设备；清除站点数据即重置。
3. **图片版权**：当前占位图来自 Unsplash（商用免费），替换为实拍作品时注意版权。
4. **移动端**：已适配 `max-width: 900px` 响应式布局，轮盘降级为横排、面板纵向排列。
